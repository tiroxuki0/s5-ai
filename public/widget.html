✨ S5 Assistant Chat Widget Demo

✨ What is this?

This is a demo page showing how the S5 Assistant Chat Widget works. The widget is embedded on this page and appears as a floating chat button in the bottom-right corner.

Click the orange chat button to open the AI assistant and start chatting!

🔧 How to Embed

To add this widget to your website, simply include this script tag in your HTML:

<script
  src="https://your-domain.com/embed.js"
  data-api-url="https://your-domain.com/api/widget/chat"
  data-theme="auto"
  data-position="bottom-right"
  data-primary-color="#ff4d00">
</script>

🎨 Customization Options

Theme

data-theme="auto" // Follows system preference
data-theme="light" // Always light mode
data-theme="dark" // Always dark mode

Position

data-position="bottom-right" // Default
data-position="bottom-left" // Alternative

Colors

data-primary-color="#ff4d00" // Orange (default)
data-primary-color="#3b82f6" // Blue
data-primary-color="#10b981" // Green
💡 Note: Make sure to replace https://your-domain.com with your actual domain where the widget files are hosted.
